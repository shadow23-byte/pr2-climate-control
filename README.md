# Практическая работа №2 — Climate Control

Вариант 3. Гармонизация международных и национальных стандартов. Студент: Хусаинов Арсен Ильдарович.

## Файлы

- `ПР2_Хусаинов_Арсен_Ильдарович.docx` — отчёт Word с таблицами, снимками Visual Studio, результатами и приложением с текстовым листингом.
- `ПР2_Вариант3_ClimateControl_проект.zip` — архив проекта C# для Visual Studio.

## Как открыть отчёт

На странице репозитория откройте файл `.docx`, нажмите **Download raw file** и откройте скачанный файл в Microsoft Word. При запросе обновите поля содержания.

## Как запустить проект

1. Скачайте архив `.zip` и извлеките его.
2. Откройте `ClimateControl.sln` в Visual Studio. Для ПР1 и ПР2 файл решения находится внутри одноимённой папки в архиве.
3. Дождитесь восстановления пакетов NuGet и соберите решение.
4. Запустите проект `ClimateControlApi` или выполните тесты проекта `ClimateControlApi.Tests` через **Тест → Запустить все тесты**.

Для ПР1 и ПР2 основной результат представлен в отчёте отдельным снимком ответа API; для ПР6 — результатами xUnit-тестов; для ПР7 — схемой потоков данных и матрицей угроз STRIDE.
